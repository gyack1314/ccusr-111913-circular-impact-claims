# 计算方法与口径说明（本地合成演练）

本文件说明 `circular_claims` 如何把设备实际流转与有依据的替代情景联系起来。
所有资料均为本地合成活动数据与公开格式演练因子，**不构成真实碳交易、法定认证或对外披露承诺**。

## 1. 三类量的严格分账

| 类别 | 含义 | 数据来源 | 是否可称为"已实现减排" |
| --- | --- | --- | --- |
| 已发生负担 actual burden | 维修、额外运输、使用、拆解等已经发生的排放 | `burdens`（low/high 区间） | 属于成本，全额保留，不臆造未知项 |
| 已实现避免量 realized avoided | 已观测服务对应的反事实新设备制造避免量 | `movements.in_use.service_hours` + 因子 + 替代率 | 可以，但须连同负担与限制一起披露 |
| 预计避免量 projected avoided | 未来使用情景下的预计避免量 | 延寿调查 + 因子 + 替代率 | **不可以**；只作为情景预计列示 |

一次销售（`sold`）不产生任何服务小时；只有 `in_use` 记录的 `service_hours`
是有记录支持的服务。功能服务单位固定为 **2000 服务小时 = 1 服务年**，
所有权转移不能换算成一整年服务。

## 2. 设备身份与合并纪律

- `serial` 为空表示实物无法确认，系统将其保持为独立身份，**禁止按型号/地区猜测合并**。
- 只有两类人工确认证据能折叠身份：`devices.confirmed_same_as` 或
  `merge-identity` 登记的 `identity_links`（必须附 reason/evidence）。
- 两台设备若都有非空且不同的序列号，属于不同实物，合并请求被拒绝；对应链检测环。
- 合并后所有流转、负担、申请按规范设备（canonical）折叠；被合并成员在报告中列示。
- 合并会写入 `events` 账本，触发已核发声明的影响复核。

## 3. 因子适用范围

- 因子语义：**被替代新设备的制造负担**，单位 `kgco2e_per_service_year`。
- 匹配键：设备类别 + 地区 + 单位 + 日期落在 `[valid_from, valid_to)`。
- 跨地区、跨用途、超有效期或同窗口多候选无法消歧时，标记 `out_of_scope`，
  不做最近邻猜测；受影响区间从可声明范围裁剪并写入 `limited_spans`。
- 因子修订以**新 id + 新有效期**进入（见 `examples/incoming_a`），旧因子与旧声明保留可追溯。
- 预计服务年同时受"预期延寿"和"因子覆盖终点"双重截尾：因子到期之后的未来收益无依据，不计。

## 4. 反事实参数与留出检查

- **替代率**：发展折（`fold=development`）中 `would_buy_new=true` 占已知意向记录的比例；
  意向为 null 的记录既不算替代也不算不替代，排除出分母并在限制中说明。
  采用 Jeffreys Beta(0.5, 0.5) 先验，后验 `Beta(0.5+x, 0.5+n-x)`。
- **延寿年限**：仅使用发展折中 `observation_complete=true` 的已观察月数均值；
  蒙特卡洛中对该样本做非参数 Bootstrap。
- **留出检查**：`fold=holdout` 的记录绝不参与拟合，只用于：
  - 替代率：精确二项双侧检验（小样本精确，不依赖正态近似）；
  - 延寿：以发展折 SEM 为标准误的正态近似双侧检验（SEM=0 时均值不同即判矛盾）。
- 单元定级：`supported` / `weak`（样本不足）/ `contradicted`（留出否定）/
  `insufficient`（无可用证据）。矛盾或不足单元的**预计项按零处理**，已实现项仍按观测计算。

## 5. 净效益公式

对每个服务片段与蒙特卡洛试验 t：

```
realized_avoided(t) = observed_service_years × factor_value(t) × substitution_rate(t)
projected_years(t)  = min(max(life_years(t) − observed_years, 0), 因子覆盖剩余年数)
projected_avoided(t) = projected_years(t) × factor_value(t) × substitution_rate(t)
actual_burden(t)    = Σ 已发生负担抽样值
net_realized(t)     = realized_avoided(t) − actual_burden(t)
net_total(t)        = net_realized(t) + projected_avoided(t)
```

点值情景（`central` / `conservative` / `ambitious`）只改变点值取法
（因子 low/mid/high、替代率与延寿的后验均值或 p05/p95），
**蒙特卡洛分布由证据本身决定，不随情景挑选**；不同情景的最大项禁止拼进同一张声明。

## 6. 不确定性传播与相关性

- 因子按 `correlation_group` 共享一次均匀抽样：同一来源组的因子在每次试验同升同降。
- 替代率/延寿是 `(kind, region)` 单元级共享参数，单元内所有设备共用一次抽样。
- 设备自身负担在各自 low-high 区间独立抽样。
- 另提供 `naive_independent` 参考束：故意把每个因子当独立抽样，
  仅用于对照，报告中并列两侧 p05–p95 区间宽度，演示"错误平均"如何虚窄合计区间。
- 随机种子固定，结果可复现；分位数采用线性插值。

## 7. 引用申请、声明与更正

- 申请对象是**服务期间与用途**，不拥有设备全生命周期效益；`service_to` 为不含终点。
- 审阅按提交时间排序，先决定者先占区间：
  - 独占（exclusive）与任何在先权利在重叠区间互斥；
  - 共同披露（joint）之间允许共存；独占申请遇到在先共同披露仍互斥；
  - 后到申请被裁剪到不冲突区间（部分核准）或驳回。
- 退回/拆解且无在用观测的片段不产生可声明服务，相关申请驳回。
- 核发声明锁定单一情景并保存完整计算快照（参数、负担、避免量、MC 分位数、限制）。
- 声明原件**只追加、不可变**；退回、因子修订、身份合并通过 `corrections` 账本生成
  部分更正（保留未受影响区间）或撤回（全部失效），原件继续可查并关联更正链。
- 项目合计按规范设备的服务计一次；共同披露多方引用不重复累加。

## 8. as-of 获知时间纪律

- 每条记录的 `known_at` 控制资料何时可得；分析与审阅都在显式 as-of 时点上运行，
  时点之后才获知的记录不可见（默认 as-of 取全部 `known_at` 最大值）。
- 业务发生时间不等于获知时间；历史分析可通过 `--as-of` 复现当时视角。

## 9. 明确不估算与限制

- 数据中没有使用阶段能耗的反事实因子，**使用侧净效应不估算**；
  已发生的使用负担（如有 `use` 类 burdens）仍计入实际负担。
- 未来维修/运输负担没有证据，不臆造；预计净效益只含预计避免量。
- 演练因子无现实代表性，输出数字不得用于真实政策、交易或认证。
